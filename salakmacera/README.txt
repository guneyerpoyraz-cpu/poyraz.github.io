# salakmacera.com

Bu klasör, statik bir web sitesi olarak hazırlanmıştır.

## Dosyalar
- index.html — Sayfaların yapısı
- style.css — Tasarım
- script.js — Macera ve matematik testlerinin çalışması

## Bilgisayarda çalıştırma
index.html dosyasına çift tıklayarak tarayıcıda açabilirsin.

## İnternete koyma
Bu dosyalar GitHub Pages, Cloudflare Pages, Netlify veya benzeri statik site servislerine yüklenebilir.
Alan adı olarak salakmacera.com kullanılabilir.
